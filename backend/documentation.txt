## Backend API Layer

Completed by Person 2.

### Implemented Endpoints

#### Get All Books

GET /api/books

Returns all books from DynamoDB.

#### Get Single Book

GET /api/books/:id

Returns a single book by ID.

#### Create Book

POST /api/books

Creates a new book record.

#### Update Book

PUT /api/books/:id

Updates an existing book.

#### Delete Book

DELETE /api/books/:id

Deletes a book record.
